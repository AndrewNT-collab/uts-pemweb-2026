Project UTS Mata Kuliah Pemrograman Web yang dibuat menggunakan HTML, Laravel, VScode, JavaScript, dan PHP.

Website ini dibuat sebagai tugas Ujian Tengah Semester (UTS) Pemrograman Web 2026.
Tujuan utama pembuatan website ini adalah sebagai Portofolio Laporan Project Akhir menggunakan Docker, Laravel, dan VScode

Dalam website portofolio ini, hampir semua bagian dibuat dengan bentuk Dynamic agar dapat diubah langsung dari Dashboard admin tanpa harus mengubahnya di dalam VScode atau biasa disebut Hardcode

Proses Pembuatan Website
Tahapan pengembangan website dilakukan sebagai berikut:
1. Analisis Kebutuhan
Menentukan tujuan website dan fitur yang akan dibuat berdasarkan kebutuhan tugas UTS.
2. Pembuatan User Interface
Mendesain tampilan website menggunakan HTML agar mudah digunakan dan memiliki tampilan yang menarik.
3. Implementasi Backend
Menggunakan PHP untuk menghubungkan website dengan database serta mengelola proses CRUD (Create, Read, Update, Delete).
4. Pengujian
Melakukan testing pada setiap fitur untuk memastikan website berjalan sesuai dengan yang diharapkan.
